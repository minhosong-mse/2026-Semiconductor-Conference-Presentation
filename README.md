## From Coursework to Conference

본 발표는 **반도체공정과화학분석** 수업 프로젝트에서 시작했습니다.

ALD High-k 박막의 밀도와 계면 거칠기를 정량화하기 위해  
Spectroscopic Ellipsometry와 X-ray 계열 계측의 상보성을 문헌 기반으로 검토하고,  
서로 다른 계측 범위와 민감도를 결합하는 Hybrid Metrology 접근을 제안했습니다.

수업 프로젝트 이후 외부 피드백을 반영하여 **3D 패턴 대응, 측정 영역 차이, 양산 적용 가능성**을 추가로 검토했고,  
그 내용을 반도체공학회 특별세션에서 발표했습니다.

**Related Technical Project:**

## Q&A and Feedback

발표 과정에서 **3D 패턴 대응과 측정 영역 차이를 고려해 양산 가능성 검토를 보완한 점**에 대한 긍정적인 피드백을 받았습니다.

동시에, 분석이 High-k 박막과 계면 특성에 집중되어 있다는 점에서  
**계면 아래 기판 또는 인접층과의 상호작용까지 함께 검토할 필요가 있다**는 질문을 받았습니다.

이 피드백을 통해 계면을 독립적인 경계로만 해석하기보다  
박막–계면층–기판이 연결된 구조로 확장해야 한다는 후속 방향을 정리했습니다.
